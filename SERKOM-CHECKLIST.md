## Catatan sebelum ujian
- Ganti nama/inisial dan email pada portfolio sesuai identitas sendiri.
- Jika perlu, ganti URL GitHub.
- Jalankan kedua frontend dan backend untuk demo.
- Import SQL sebelum login/checkout.
- Jangan menghapus `.env.example` dari submission.
